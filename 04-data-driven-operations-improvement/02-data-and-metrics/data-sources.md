# Data Sources – Operations Improvement

## Purpose
Identify the primary data sources used to assess operational performance and support improvement decisions.

## Automation Systems
- PLC event logs (state changes, faults, run hours)
- SCADA alarms and acknowledgements
- WCS transaction logs (routing, exceptions, throughput)
- WMS order and inventory data

## Maintenance Systems
- CMMS work orders
- Preventive maintenance schedules
- Breakdown and corrective maintenance records

## Operational Inputs
- Shift handover reports
- Incident logs and postmortems
- Manual performance checks and observations

## Data Characteristics
- Mix of real-time and historical data
- Event-driven with timestamped records
- Varying data quality across systems

## Limitations
- Inconsistent naming conventions
- Gaps during system restarts or outages
- Manual inputs subject to human error
