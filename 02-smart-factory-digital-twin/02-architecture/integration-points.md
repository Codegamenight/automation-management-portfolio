# Integration Points

## OT ↔ SCADA
- Real-time status
- Alarms and events
- Equipment health data

## SCADA ↔ WCS
- Equipment availability
- Command execution feedback
- Fault and recovery signals

## WCS ↔ WMS
- Order release
- Routing and confirmation
- Exception handling

## WMS ↔ ERP
- Inventory updates
- Shipment confirmation
- Demand signals

## Data Integration
- Event-driven messaging
- Near real-time telemetry
- Historical data for analytics
