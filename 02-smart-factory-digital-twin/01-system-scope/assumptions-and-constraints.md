# Assumptions and Constraints

## Assumptions
- Warehouse operates 16–24 hours/day
- Automation is mission-critical to throughput
- Standard WMS exists upstream
- PLC/SCADA layer controls equipment
- Event data is available for analytics

## Constraints
- Fixed building layout
- Maintenance windows limited by production
- Vendor-specific interfaces exist
- Cybersecurity policies apply to OT networks
- Safety standards must not be compromised
