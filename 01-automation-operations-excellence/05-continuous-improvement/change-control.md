# Change Control Process – Automation Operations

## Purpose
Ensure that changes to automation systems are implemented safely, predictably, and with minimal operational risk.

## Change Types
- Standard Change: Low risk, pre-approved
- Normal Change: Requires review and approval
- Emergency Change: Immediate implementation with retrospective review

## Change Workflow
1. Change request submitted
2. Impact and risk assessed
3. Approval obtained
4. Change implemented during approved window
5. Validation performed
6. Change documented and closed

## Roles
- Change Requester: Initiates change
- Automation Manager: Technical approval
- Operations Manager: Operational approval

## Governance
- All changes logged
- Emergency changes reviewed within 48 hours
