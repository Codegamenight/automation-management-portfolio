# KPI Dashboard Specification

## Audience
- Operations Manager
- Automation Manager
- Senior Management

## Dashboard Sections

### Section 1: Reliability Overview
- Availability (trend)
- MTBF (trend)
- Incident volume (weekly)

### Section 2: Responsiveness
- MTTR (average and worst-case)
- Escalation response time

### Section 3: Maintenance Health
- PM compliance
- Overdue PM tasks
- Repeat incident rate

## Data Sources
- Maintenance logs
- Incident reports
- Production downtime records

## Update Frequency
- Daily snapshot
- Weekly management review
- Monthly executive summary
